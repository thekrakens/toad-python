# Auto-Sync Setup Guide\n\nSet up TOAD to automatically sync every 5 minutes using your system's scheduler.\n\n## macOS Setup (Recommended: launchd)\n\n### Option 1: Using launchd (Native macOS)\n\n1. **Create a launchd plist file:**\n\n```bash\n# Create the launch agent directory if it doesn't exist\nmkdir -p ~/Library/LaunchAgents\n\n# Create the plist file\ncat > ~/Library/LaunchAgents/com.toad.sync.plist << 'EOF'\n<?xml version=\"1.0\" encoding=\"UTF-8\"?>\n<!DOCTYPE plist PUBLIC \"-//Apple//DTD PLIST 1.0//EN\" \"http://www.apple.com/DTDs/PropertyList-1.0.dtd\">\n<plist version=\"1.0\">\n<dict>\n    <key>Label</key>\n    <string>com.toad.sync</string>\n    \n    <key>ProgramArguments</key>\n    <array>\n        <string>/bin/bash</string>\n        <string>-c</string>\n        <string>cd /Users/thekrakens/Documents/Projects/toad-python && /Users/thekrakens/Library/Caches/pypoetry/virtualenvs/toad-python-F6t7MFVY-py3.11/bin/python -m toad.cli sync</string>\n    </array>\n    \n    <key>StartInterval</key>\n    <integer>300</integer>\n    \n    <key>StandardOutPath</key>\n    <string>/tmp/toad-sync.log</string>\n    \n    <key>StandardErrorPath</key>\n    <string>/tmp/toad-sync-error.log</string>\n    \n    <key>RunAtLoad</key>\n    <true/>\n</dict>\n</plist>\nEOF\n```\n\n2. **Load the launch agent:**\n\n```bash\nlaunchctl load ~/Library/LaunchAgents/com.toad.sync.plist\n```\n\n3. **Start the service:**\n\n```bash\nlaunchctl start com.toad.sync\n```\n\n4. **View logs:**\n\n```bash\n# Sync output\ntail -f /tmp/toad-sync.log\n\n# Errors\ntail -f /tmp/toad-sync-error.log\n```\n\n5. **Stop/Remove auto-sync:**\n\n```bash\n# Stop\nlaunchctl stop com.toad.sync\n\n# Unload (disable)\nlaunchctl unload ~/Library/LaunchAgents/com.toad.sync.plist\n\n# Remove permanently\nrm ~/Library/LaunchAgents/com.toad.sync.plist\n```\n\n### Option 2: Using cron (Unix/Linux compatible)\n\n1. **Edit crontab:**\n\n```bash\ncrontab -e\n```\n\n2. **Add this line:**\n\n```cron\n*/5 * * * * cd /Users/thekrakens/Documents/Projects/toad-python && /Users/thekrakens/Library/Caches/pypoetry/virtualenvs/toad-python-F6t7MFVY-py3.11/bin/python -m toad.cli sync >> /tmp/toad-sync.log 2>&1\n```\n\n3. **View crontab:**\n\n```bash\ncrontab -l\n```\n\n4. **Remove cron job:**\n\n```bash\ncrontab -e\n# Delete the line\n```\n\n## Linux Setup\n\n### Using systemd (Recommended for modern Linux)\n\n1. **Create service file:**\n\n```bash\nsudo nano /etc/systemd/system/toad-sync.service\n```\n\n```ini\n[Unit]\nDescription=TOAD Productivity Sync\nAfter=network.target\n\n[Service]\nType=oneshot\nUser=yourusername\nWorkingDirectory=/path/to/toad-python\nExecStart=/path/to/poetry run toad sync\nStandardOutput=append:/var/log/toad-sync.log\nStandardError=append:/var/log/toad-sync-error.log\n\n[Install]\nWantedBy=multi-user.target\n```\n\n2. **Create timer file:**\n\n```bash\nsudo nano /etc/systemd/system/toad-sync.timer\n```\n\n```ini\n[Unit]\nDescription=Run TOAD sync every 5 minutes\nRequires=toad-sync.service\n\n[Timer]\nOnBootSec=1min\nOnUnitActiveSec=5min\nUnit=toad-sync.service\n\n[Install]\nWantedBy=timers.target\n```\n\n3. **Enable and start:**\n\n```bash\nsudo systemctl daemon-reload\nsudo systemctl enable toad-sync.timer\nsudo systemctl start toad-sync.timer\n```\n\n4. **Check status:**\n\n```bash\nsystemctl status toad-sync.timer\njournalctl -u toad-sync.service -f\n```\n\n## Windows Setup\n\n### Using Task Scheduler\n\n1. **Create batch script** (`toad-sync.bat`):\n\n```batch\n@echo off\ncd C:\\path\\to\\toad-python\npoetry run toad sync >> C:\\logs\\toad-sync.log 2>&1\n```\n\n2. **Open Task Scheduler:**\n   - Press `Win + R`, type `taskschd.msc`, press Enter\n\n3. **Create Task:**\n   - Action → Create Task\n   - Name: \"TOAD Sync\"\n   - Trigger: New → Repeat task every 5 minutes\n   - Action: Start a program → Browse to `toad-sync.bat`\n   - Conditions: Uncheck \"Start only if on AC power\"\n\n## Python-based Scheduler (Cross-platform)\n\nIf you prefer a pure Python solution:\n\n### 1. Install schedule library:\n\n```bash\npoetry add schedule\n```\n\n### 2. Create scheduler script (`scripts/auto_sync.py`):\n\n```python\n#!/usr/bin/env python3\n\"\"\"\nAuto-sync scheduler for TOAD.\nRuns sync command every 5 minutes.\n\"\"\"\n\nimport schedule\nimport time\nimport subprocess\nimport logging\nfrom pathlib import Path\nfrom datetime import datetime\n\n# Setup logging\nlog_file = Path.home() / \".toad\" / \"auto_sync.log\"\nlog_file.parent.mkdir(exist_ok=True)\n\nlogging.basicConfig(\n    level=logging.INFO,\n    format='%(asctime)s - %(levelname)s - %(message)s',\n    handlers=[\n        logging.FileHandler(log_file),\n        logging.StreamHandler()\n    ]\n)\n\ndef run_sync():\n    \"\"\"Run the TOAD sync command.\"\"\"\n    try:\n        logging.info(\"Starting sync...\")\n        result = subprocess.run(\n            [\"poetry\", \"run\", \"toad\", \"sync\"],\n            capture_output=True,\n            text=True,\n            check=True\n        )\n        logging.info(f\"Sync completed successfully: {result.stdout}\")\n    except subprocess.CalledProcessError as e:\n        logging.error(f\"Sync failed: {e.stderr}\")\n    except Exception as e:\n        logging.error(f\"Unexpected error: {e}\")\n\n# Schedule sync every 5 minutes\nschedule.every(5).minutes.do(run_sync)\n\n# Run immediately on startup\nrun_sync()\n\nlogging.info(\"Scheduler started. Syncing every 5 minutes...\")\n\n# Keep running\nwhile True:\n    schedule.run_pending()\n    time.sleep(1)\n```\n\n### 3. Run the scheduler:\n\n```bash\npoetry run python scripts/auto_sync.py\n```\n\n### 4. Run in background (macOS/Linux):\n\n```bash\nnohup poetry run python scripts/auto_sync.py > /tmp/toad-scheduler.log 2>&1 &\n```\n\n## Quick Setup Script (macOS)\n\nWe've provided a setup script for easy installation:\n\n```bash\n# Run the setup script\nbash scripts/setup_auto_sync.sh\n```\n\n## Monitoring\n\n### Check if sync is running:\n\n**macOS (launchd):**\n```bash\nlaunchctl list | grep toad\ntail -f /tmp/toad-sync.log\n```\n\n**Linux (systemd):**\n```bash\nsystemctl status toad-sync.timer\njournalctl -u toad-sync.service -f\n```\n\n**Cron:**\n```bash\ntail -f /tmp/toad-sync.log\n```\n\n## Troubleshooting\n\n### Sync not running?\n\n1. **Check logs:**\n   - macOS: `/tmp/toad-sync.log` and `/tmp/toad-sync-error.log`\n   - Linux: `journalctl -u toad-sync.service`\n\n2. **Verify paths:**\n   - Ensure Python/Poetry paths are correct\n   - Check working directory exists\n\n3. **Test manually:**\n   ```bash\n   cd /path/to/toad-python\n   poetry run toad sync\n   ```\n\n4. **Check permissions:**\n   ```bash\n   ls -la ~/Library/LaunchAgents/com.toad.sync.plist\n   ```\n\n### Common Issues\n\n- **Environment variables:** Schedulers may not load your shell environment. Add `.env` file path explicitly if needed.\n- **Poetry not found:** Use full path to poetry executable\n- **Notion API limits:** If syncing too frequently, Notion may rate-limit. Adjust interval if needed.\n\n## Performance Tips\n\n- **Incremental sync** runs in 2-5 seconds (default mode)\n- **Monitor cache:** Check `~/.toad/sync_cache.json` for last sync times\n- **Clear cache if needed:** `poetry run toad sync --clear-cache`\n- **Full sync weekly:** Schedule a full sync weekly with cron:\n  ```cron\n  0 2 * * 0 cd /path/to/toad-python && poetry run toad sync --full\n  ```\n
