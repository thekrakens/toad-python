# Feature Specification: Exercise Tracking (v0.3.2)

## Overview

Add comprehensive exercise tracking to TOAD by parsing individual exercises from Gymaholic workouts, tracking progressions, and providing intelligent progression suggestions.

## Goals

1. Parse individual exercises from Gymaholic CSV files
2. Create Exercise database in Notion to track exercise metadata and history
3. Track individual exercise performance (reps, weights, times, etc.)
4. Store progression rules in TOAD config file
5. Suggest when to progress on individual exercises
6. Categorize exercises by type and track personal records

## Exercise Database Schema

### Notion Database: Exercises

| Property | Type | Description |
|----------|------|-------------|
| **Name** | Title | Exercise name (e.g., "Bench Press", "Pull-ups") |
| **Category** | Select | Exercise category (Warmup, Climbing, Weights, Cardio, Stretching) |
| **Body Parts** | Multi-select | Target body parts (Chest, Back, Legs, Arms, Core, Full Body) |
| **Equipment** | Select | Equipment type (Barbell, Dumbbell, Bodyweight, Machine, Resistance Band, Other) |
| **Progression Type** | Select | How to progress (Weight, Reps, Time, Distance, Levels) |
| **Progression Scale** | Number | Default increment (e.g., 5 for +5lbs, 1 for +1 rep) |
| **Current PR** | Text/Formula | Personal record (formatted based on progression type) |
| **PR Date** | Date | When PR was achieved |
| **Last Performed** | Date | Most recent workout with this exercise |
| **Total Sessions** | Number | Count of workouts including this exercise |
| **Notes** | Rich Text | Exercise notes, form cues, etc. |
| **Related Workouts** | Relation | Link to Workout database |

### Parser Implementation

```python
class GymaholicExerciseParser:
    """Parse individual exercises from Gymaholic CSV."""

    def parse_exercises(self, csv_path: Path) -> List[Exercise]:
        """
        Parse exercises from Gymaholic CSV.

        Returns:
            List of Exercise objects with sets grouped
        """
        df = pd.read_csv(csv_path)

        # Group by exercise name
        exercises = []
        for exercise_name, group in df.groupby('Exercise'):
            exercise = Exercise(
                name=exercise_name,
                category=self._map_set_type(group.iloc[0]['Set Type']),
                sets=self._parse_sets(group)
            )
            exercises.append(exercise)

        return exercises

    def _parse_sets(self, group: pd.DataFrame) -> List[ExerciseSet]:
        """Parse individual sets for an exercise."""
        sets = []
        for idx, row in group.iterrows():
            sets.append(ExerciseSet(
                set_number=len(sets) + 1,
                reps=row['Reps'],
                weight=row['Weight'],
                time=row['Time'],
                rest=row['Rest']
            ))
        return sets

    def _map_set_type(self, set_type: str) -> str:
        """Map Gymaholic set type to TOAD category."""
        mapping = {
            'Warmup': 'Warmup',
            'Normal': 'Weights',
            'Dropset': 'Weights',
            'Superset': 'Weights',
        }
        return mapping.get(set_type, 'Weights')
```

### Config Loader

```python
class ExerciseConfig:
    """Load and manage exercise progression rules."""

    def __init__(self, config_path: Optional[Path] = None):
        self.config_path = config_path or Path.home() / ".toad" / "exercise_config.yaml"
        self.config = self._load_config()

    def get_progression_rule(self, exercise_name: str) -> Dict[str, Any]:
        """Get progression rule for an exercise."""
        if exercise_name in self.config.get('progressions', {}):
            return self.config['progressions'][exercise_name]

        # Return default based on exercise category
        return self.config.get('defaults', {})

    def get_exercise_metadata(self, exercise_name: str) -> Dict[str, Any]:
        """Get metadata for an exercise."""
        return self.config.get('exercises', {}).get(exercise_name, {})
```

## Progression Suggestion Algorithm

### Logic

```python
class ProgressionSuggester:
    """Suggest when to progress on exercises."""

    def analyze_progression(self, exercise: Exercise, history: List[ExerciseSession]) -> Dict[str, Any]:
        """
        Analyze exercise history and suggest progression.

        Args:
            exercise: Exercise metadata from database
            history: Last 3-5 sessions of this exercise

        Returns:
            {
                'ready_to_progress': bool,
                'suggestion': str,
                'reason': str,
                'next_target': str
            }
        """
        config = self.exercise_config.get_progression_rule(exercise.name)

        # Check if last N sessions were successful
        recent_sessions = history[-3:]  # Last 3 sessions
        successful_sessions = 0

        for session in recent_sessions:
            if self._is_successful_session(session, config):
                successful_sessions += 1

        if successful_sessions >= config.get('min_success_sets', 3):
            next_target = self._calculate_next_target(exercise, config)
            return {
                'ready_to_progress': True,
                'suggestion': f"Ready to progress to {next_target}!",
                'reason': f"Completed {successful_sessions} consecutive successful sessions",
                'next_target': next_target
            }

        return {
            'ready_to_progress': False,
            'suggestion': "Continue with current weight/reps",
            'reason': f"Need {config['min_success_sets'] - successful_sessions} more successful sessions",
            'next_target': None
        }

    def _is_successful_session(self, session: ExerciseSession, config: Dict[str, Any]) -> bool:
        """Check if session meets success criteria."""
        if config['type'] == 'weight':
            # All sets must hit target reps
            target_reps = config.get('target_reps', 8)
            successful_sets = sum(1 for s in session.sets if s.reps >= target_reps)
            return successful_sets >= config.get('min_success_sets', 3)

        elif config['type'] == 'reps':
            # Hit target reps
            max_reps = max(s.reps for s in session.sets)
            return max_reps >= config.get('target_reps', 12)

        elif config['type'] == 'time':
            # Hit target time
            max_time = max(s.time for s in session.sets)
            return max_time >= config.get('target_time', 60)

        return False

    def _calculate_next_target(self, exercise: Exercise, config: Dict[str, Any]) -> str:
        """Calculate next progression target."""
        if config['type'] == 'weight':
            current = exercise.current_weight
            next_weight = current + config['scale']
            return f"{next_weight} lbs"

        elif config['type'] == 'reps':
            current = exercise.current_reps
            next_reps = current + config['scale']
            return f"{next_reps} reps"

        elif config['type'] == 'time':
            current = exercise.current_time
            next_time = current + config['scale']
            return f"{next_time} seconds"

        return "Unknown"
```

## Personal Record (PR) Tracking

### PR Detection

```python
class PRTracker:
    """Track and detect personal records."""

    def check_for_pr(self, exercise: Exercise, session: ExerciseSession) -> Optional[PersonalRecord]:
        """
        Check if session contains a new PR.

        Args:
            exercise: Exercise from database with current PR
            session: New exercise session

        Returns:
            PersonalRecord if new PR detected, None otherwise
        """
        progression_type = exercise.progression_type

        if progression_type == 'Weight':
            # Check for max weight at target reps
            return self._check_weight_pr(exercise, session)

        elif progression_type == 'Reps':
            # Check for max reps
            return self._check_reps_pr(exercise, session)

        elif progression_type == 'Time':
            # Check for max time
            return self._check_time_pr(exercise, session)

        return None

    def _check_weight_pr(self, exercise: Exercise, session: ExerciseSession) -> Optional[PersonalRecord]:
        """Check for weight-based PR."""
        # Get max weight with at least target reps
        target_reps = 8  # From config
        qualifying_sets = [s for s in session.sets if s.reps >= target_reps]

        if not qualifying_sets:
            return None

        max_weight = max(s.weight for s in qualifying_sets)

        if exercise.current_pr_weight is None or max_weight > exercise.current_pr_weight:
            return PersonalRecord(
                exercise=exercise.name,
                type='weight',
                value=max_weight,
                reps=target_reps,
                date=session.date
            )

        return None

    def format_pr(self, pr: PersonalRecord) -> str:
        """Format PR for display."""
        if pr.type == 'weight':
            return f"{pr.value} lbs x {pr.reps} reps"
        elif pr.type == 'reps':
            return f"{pr.value} reps"
        elif pr.type == 'time':
            return f"{pr.value} seconds"
        return str(pr.value)
```

## Integration with Event-Driven Handler

### Updated Workflow

1. **Parse Gymaholic CSV**: Extract workout + individual exercises
2. **Reconcile Workout**: Match/create workout in Notion (existing logic)
3. **Process Exercises**: For each exercise in the workout:
   - Look up or create Exercise in Exercise database
   - Update exercise metadata (last performed, total sessions)
   - Check for PR
   - Append exercise details to workout Notes field
   - Check if ready to progress
4. **Update Workout Notes**: Add formatted exercise list with progression suggestions

### Handler Updates

```python

    """Handle Gymaholic workout CSV with exercise parsing."""
    # ... existing staging code ...

    # Parse workout AND exercises
    workout = self.gymaholic_parser.parse(staging_path)
    exercises = self.exercise_parser.parse_exercises(staging_path)

    # Reconcile workout (existing logic)
    matched_workout = self.reconciler.match_workout(workout, existing_workouts)

    # Process exercises
    exercise_notes = []
    progression_suggestions = []

    for exercise in exercises:
        # Look up or create exercise in Notion
        exercise_page = self.notion_sync.get_or_create_exercise(exercise)

        # Check for PR
        pr = self.pr_tracker.check_for_pr(exercise_page, exercise)
        if pr:
            self.notion_sync.update_exercise_pr(exercise_page, pr)

            exercise_page,

        # Merge with existing
        updated_properties = self.reconciler.merge_workouts(workout, matched_workout)
        updated_properties['Notes'] = workout_notes
    else:
        # Create new
        result = self.notion_sync.sync_workout(workout, notes=workout_notes)
```
