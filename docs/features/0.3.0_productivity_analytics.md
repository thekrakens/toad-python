## Overview

### Problem Statement

Currently have rich productivity data across multiple Notion databases (Tasks, Time Entries, Daily Metrics), but:
- **No charting capabilities** for analyzing time allocation by task type, project, or week/month
- **No automated weekly reports** to review what was accomplished
- **Data is scattered** across multiple tables making it hard to aggregate insights

### Goals

- **G1**: Create time-series data for charting hours worked by task type, project, day/week/month
- **G2**: Enable Notion chart views showing planned vs actual hours
- **G3**: Generate automated weekly summary reports using LLM
- **G4**: Provide historical weekly reports for reference

## Current Data Model

### Existing Databases

**Tasks** (`2042579666bd81f5b759e03fe4eb42f2`):
- Task Type (multi_select): coding, meeting, planning, fixing, etc.
- Projects (relation)
- Time Entries (relation)
- Planned Hrs. (formula)
- Logged Hrs. (formula) - calculated from Time Entries
- Status (status): not started, in progress, done, etc.
- Dates: Planned, Doing, Done, Due

**Time Entries** (`20425796-66bd-8143-b976-eff463de13da`):
- Start/End (dates)
- Task (relation)
- Duration calculated from Start/End

**Daily Productivity Metrics** (`2352579666bd8017a464c1a7d32d35c4`):
- Date
- Relations to Tasks: Planned, Active, Worked, Done
- Metrics: Effective Hours Worked, Planned Working Hours, etc.
- (Note: Hours fields currently empty - need to populate via ETL)

## Solution Architecture

### Part 1: Productivity Stats ETL

**Similar to Health Stats ETL** we just built, create a time-series database for charting.

#### New Database: Productivity Stats

| Property | Type | Description | Example |
|----------|------|-------------|---------|
| title | Title | Auto: "{metric} - {date}" | "coding_hours - 2026-01-18" |
| date | Date | Date of metric | 2026-01-18 |
| week | Formula | ISO week number | 2026-W03 |
| month | Formula | Month-year | 2026-01 |
| metric_type | Select | Type of metric | hours_worked, tasks_completed |
| dimension | Select | What it's grouped by | task_type, project, overall |
| dimension_value | Text | Specific value | "coding", "TOAD v0.2.0" |
| value | Number | The metric value | 28.5 |

**Select Options:**
- `metric_type`: hours_worked, hours_planned, tasks_completed, tasks_planned
- `dimension`: task_type, project, overall, status

#### ETL Process Flow

```
┌─────────────────────────────────────────────────────────────┐
│ EXTRACT: Query source databases                             │
├─────────────────────────────────────────────────────────────┤
│ 1. Time Entries → aggregate hours by date                   │
│ 2. Tasks → join to get task type, project, logged hours     │
│ 3. Daily Metrics → get planned hours, task counts           │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│ TRANSFORM: Convert to time-series format                    │
├─────────────────────────────────────────────────────────────┤
│ For each date:                                               │
│   For each task type (coding, meeting, etc.):                │
│     → Row: hours_worked | task_type | "coding" | 8.5        │
│   For each project:                                          │
│     → Row: hours_worked | project | "TOAD" | 12.3           │
│   Overall:                                                   │
│     → Row: hours_worked | overall | "all" | 28.5            │
│     → Row: hours_planned | overall | "all" | 32.0           │
│     → Row: tasks_completed | overall | "all" | 6            │
└──────────────────────┬──────────────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────────────┐
│ LOAD: Upsert to Productivity Stats                          │
├─────────────────────────────────────────────────────────────┤
│ - Create new entries if don't exist                         │
│ - Update existing by (date + metric_type + dimension +      │
│   dimension_value)                                           │
└─────────────────────────────────────────────────────────────┘
```

### Part 2: Weekly LLM Reports

#### New Database: Weekly Reports

| Property | Type | Description |
|----------|------|-------------|
| Week | Title | "2026-W03" |
| Start Date | Date | Monday of week |
| End Date | Date | Sunday of week |
| Generated | Created Time | When report was created |
| Summary | Rich Text | LLM-generated summary (in page content) |
| Total Hours | Number | Sum of hours for week |
| Tasks Completed | Number | Count of done tasks |
| Top Project | Text | Project with most hours |
| Status | Select | draft, reviewed, archived |

#### Report Generation Flow

```python
def generate_weekly_report(week_start: date, week_end: date):
    """Generate LLM-powered weekly report."""

    # 1. EXTRACT: Get all tasks completed this week
    tasks = query_tasks(
        filter={
            "property": "Done",
            "date": {"on_or_after": week_start, "before": week_end}
        }
    )

    # 2. AGGREGATE: Build context for LLM
    context = {
        "total_hours": 0,
        "tasks_by_type": {},
        "tasks_by_project": {},
        "task_details": []
    }

    for task in tasks:
        # Get page content (all blocks)
        blocks = get_page_content(task["id"])

        context["task_details"].append({
            "name": task.name,
            "type": task.task_type,
            "project": task.project,
            "hours": task.logged_hrs,
            "notes": extract_text_from_blocks(blocks)
        })

        # Aggregate stats
        context["total_hours"] += task.logged_hrs
        context["tasks_by_type"][task.type] = context.get(task.type, 0) + task.logged_hrs

    # 3. GENERATE: Send to Claude
    prompt = f"""
    Generate a weekly work summary report for the week of {week_start} to {week_end}.

    Data:
    {json.dumps(context, indent=2)}

    Create a professional summary covering:
    1. Overview: Total hours, number of tasks, main focus areas
    2. Time Allocation: Breakdown by task type and project
    3. Key Accomplishments: Major milestones or deliverables
    4. Notable Work: Specific tasks with significant progress
    5. Patterns/Insights: Any observations about productivity or focus

    Format as markdown with clear sections.
    """

    report = claude.messages.create(
        model="claude-sonnet-4-20250514",
        messages=[{"role": "user", "content": prompt}]
    )

    # 4. SAVE: Create Weekly Report page
    create_report_page(
        week=f"{week_start.year}-W{week_start.isocalendar()[1]}",
        start_date=week_start,
        end_date=week_end,
        content=report.content[0].text,
        total_hours=context["total_hours"],
        tasks_completed=len(tasks)
    )
```
