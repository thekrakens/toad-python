# Feature Specification: Exercise Tracking v2 (0.3.2)

## Problem Statement

Track individual exercise sets across workouts with context-aware goals:
- Same exercise can have different goals depending on workout type (Strength vs Power vs Hypertrophy)
- Gymaholic doesn't export target reps/weight - only actual performance
- Need to track progression, detect PRs, and auto-post to Discord
- Must handle set success/failure without goal data from source

## Core Challenges

### Challenge 1: Context-Dependent Goals
**Problem**: "Bench Press" in "TOMO A Strength" targets max weight/low reps (e.g., 5 reps), but same exercise in "TOMO A Power" targets lower weight/high reps (e.g., 12 reps).

**Solution**: Workout-type detection + context-specific goals in config

### Challenge 2: Missing Goal Data
**Problem**: Gymaholic CSV only shows actual performance (e.g., "95 lbs x 5"), not whether that was the goal or a failure.

**Solution**: Maintain goals in exercise config file, compare actual vs target during sync

### Challenge 3: Progression Tracking
**Problem**: Need to show "progression since last time" when posting workouts.

**Solution**: Store each set as database entry, query previous session of same exercise+context

## Data Model

### Exercise Sets (Flat File → Notion Database)

Each row = one set performed:

```csv
workout_name,workout_type,date,exercise,set_number,is_warmup,actual_reps,actual_weight,actual_time,target_reps,target_weight,success,volume,notes
TOMO B Strength,Strength,2026-01-24,Military Press,1,False,5,95,0,5,95,True,475,
TOMO B Strength,Strength,2026-01-24,Military Press,2,False,5,95,0,5,95,True,475,
TOMO B Strength,Strength,2026-01-24,Military Press,3,False,5,95,0,5,95,True,475,
TOMO A Power,Power,2026-01-25,Military Press,1,False,12,75,0,12,75,True,900,
TOMO A Power,Power,2026-01-25,Military Press,2,False,11,75,0,12,75,False,825,Failed last rep
```

**Key Fields**:
- `workout_type`: Detected from workout name (Strength, Power, Hypertrophy, General)
- `is_warmup`: True if set marked as warmup ("W" in Gymaholic CSV)
- `target_reps`/`target_weight`: From exercise config for this workout type
- `success`: `actual_reps >= target_reps and actual_weight >= target_weight`
- `volume`: `actual_weight * actual_reps` (for strength training volume tracking)

## Gymaholic CSV Parser

### Parsing Strategy

The Gymaholic CSV format:
```
;-----------------
;TOMO B Strength
;-----------------
;Date;Jan 23., 06:05
;Duration;1h:27m

#;Military Press;REPS;TIME;REST
W;;65 lbs x 8;;0:00
W;;75 lbs x 6;;0:00
1;;95 lbs x 5;;0:00
2;;95 lbs x 5;;0:00
3;;95 lbs x 5;;0:00
```

**Key observations**:
- Workout metadata in header (name, date, duration, calories, HR)
- Exercises start with `#;Exercise Name;REPS;TIME;REST`
- Sets with `W` prefix are warmups
- Set data format: `{weight} lbs x {reps}` or `x {reps}` for bodyweight or `{time}` for time-based

### Parser Implementation

```python
class GymaholicParser:
    """Parse Gymaholic CSV exports."""

    def parse(self, csv_path: Path) -> Tuple[WorkoutInfo, List[ExerciseSet]]:
        """
        Parse complete workout with exercise sets.

        Returns:
            (workout_info, exercise_sets)
        """
        with open(csv_path, 'r', encoding='utf-8') as f:
            lines = f.readlines()

        # Parse workout metadata
        workout_info = self._parse_workout_header(lines)

        # Parse exercise sets
        exercise_sets = self._parse_exercise_sets(lines, workout_info)

        return workout_info, exercise_sets

    def _parse_workout_header(self, lines: List[str]) -> WorkoutInfo:
        """Parse workout name, date, duration from header."""
        workout_name = None
        workout_date = None
        duration = None
        calories = None
        heart_rate = None

        for line in lines:
            if line.startswith(';') and not line.startswith(';-'):
                # Metadata line
                if ';' in line:
                    parts = line.strip(';').split(';')
                    if len(parts) == 1:
                        # Workout name
                        workout_name = parts[0].strip()
                    elif len(parts) == 2:
                        key, value = parts[0].strip(), parts[1].strip()
                        if key == 'Date':
                            workout_date = self._parse_date(value)
                        elif key == 'Duration':
                            duration = value
                        elif key == 'KCAL':
                            calories = int(value)
                        elif key == 'Heart rate':
                            heart_rate = int(value.replace(' bpm', ''))

        return WorkoutInfo(
            name=workout_name,
            date=workout_date,
            duration=duration,
            calories=calories,
            heart_rate=heart_rate
        )

    def _parse_exercise_sets(self, lines: List[str], workout_info: WorkoutInfo) -> List[ExerciseSet]:
        """Parse all exercise sets from CSV."""
        sets = []
        current_exercise = None

        for line in lines:
            if line.startswith('#;'):
                # New exercise
                parts = line.strip('#;').split(';')
                current_exercise = parts[0].strip()

            elif line and not line.startswith(';'):
                # Exercise set
                if current_exercise:
                    exercise_set = self._parse_set(line, current_exercise, workout_info)
                    if exercise_set:
                        sets.append(exercise_set)

        return sets

    def _parse_set(self, line: str, exercise_name: str, workout_info: WorkoutInfo) -> Optional[ExerciseSet]:
        """Parse a single set line."""
        parts = [p.strip() for p in line.split(';')]

        if len(parts) < 4:
            return None

        set_number_str = parts[0]
        reps_weight_str = parts[1]
        time_str = parts[2]
        rest_str = parts[3]

        # Detect warmup
        is_warmup = set_number_str == 'W'
        set_number = -1 if is_warmup else int(set_number_str) if set_number_str.isdigit() else 0

        # Parse reps/weight
        reps, weight = self._parse_reps_weight(reps_weight_str)

        # Parse time
        time_seconds = self._parse_time(time_str)

        return ExerciseSet(
            exercise_name=exercise_name,
            workout_name=workout_info.name,
            workout_date=workout_info.date,
            set_number=set_number,
            is_warmup=is_warmup,
            reps=reps,
            weight=weight,
            time=time_seconds
        )

    def _parse_reps_weight(self, s: str) -> Tuple[int, float]:
        """
        Parse reps and weight from string.

        Examples:
            "95 lbs x 5" -> (5, 95)
            "x 8" -> (8, 0)
            "25 lbs x 1" -> (1, 25)
        """
        if not s:
            return (0, 0)

        # Pattern: "{weight} lbs x {reps}" or "x {reps}"
        if ' x ' in s:
            parts = s.split(' x ')
            reps = int(parts[1].strip())

            if 'lbs' in parts[0]:
                weight = float(parts[0].replace('lbs', '').strip())
            else:
                weight = 0  # Bodyweight

            return (reps, weight)

        return (0, 0)

    def _parse_time(self, s: str) -> int:
        """Parse time string to seconds."""
        if not s or s == '0:00':
            return 0

        # Format: "M:SS"
        parts = s.split(':')
        minutes = int(parts[0])
        seconds = int(parts[1])
        return minutes * 60 + seconds
```

## Config-Aware Parser

Enhance parser to load config and enrich sets with target data:

```python
class ExerciseSetEnricher:
    """Enrich parsed exercise sets with target goals and success metrics."""

    def __init__(self, config: ExerciseConfig):
        self.config = config

    def enrich(self, workout_info: WorkoutInfo, exercise_sets: List[ExerciseSet]) -> List[EnrichedExerciseSet]:
        """
        Add target goals and success flags to exercise sets.

        Args:
            workout_info: Workout metadata
            exercise_sets: Parsed sets from CSV

        Returns:
            Enriched sets with targets and success flags
        """
        # Detect workout type
        workout_type = self._detect_workout_type(workout_info.name)

        enriched_sets = []
        for ex_set in exercise_sets:
            # Skip warmup sets for goals
            if ex_set.is_warmup:
                enriched_sets.append(EnrichedExerciseSet(
                    **ex_set.__dict__,
                    workout_type=workout_type,
                    target_reps=None,
                    target_weight=None,
                    target_time=None,
                    success=None
                ))
                continue

            # Get exercise config for this workout type
            exercise_config = self.config.get_exercise_config(ex_set.exercise_name, workout_type)

            # Extract targets
            target_reps = exercise_config.get('target_reps')
            target_weight = exercise_config.get('current_weight')
            target_time = exercise_config.get('target_time')

            # Calculate success
            success = self._is_successful_set(ex_set, exercise_config)

            # Calculate volume
            volume = ex_set.weight * ex_set.reps if ex_set.weight and ex_set.reps else 0

            enriched_sets.append(EnrichedExerciseSet(
                **ex_set.__dict__,
                workout_type=workout_type,
                target_reps=target_reps,
                target_weight=target_weight,
                target_time=target_time,
                success=success,
                volume=volume
            ))

        return enriched_sets

    def _detect_workout_type(self, workout_name: str) -> str:
        """Detect workout type from name using patterns."""
        patterns = self.config.config.get('workout_patterns', [])

        name_upper = workout_name.upper()
        for pattern_config in patterns:
            if pattern_config['pattern'] in name_upper:
                return pattern_config['type']

        return 'general'

    def _is_successful_set(self, ex_set: ExerciseSet, config: Dict[str, Any]) -> bool:
        """Check if set met success criteria."""
        # Reps-based
        if 'target_reps' in config and ex_set.reps:
            return ex_set.reps >= config['target_reps']

        # Time-based
        if 'target_time' in config and ex_set.time:
            return ex_set.time >= config['target_time']

        return False
```
