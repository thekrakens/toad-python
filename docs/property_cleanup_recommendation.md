## Recommended Property Structure

### Core Task Properties (Keep)

**BASIC INFO**
- `Name` - Title
- `Status` - Status property
- `Task Type` - Select

**PLANNING & DATES**
- `Planned` - Date Range (overall time window for task)
- `Due` - Date (hard deadline)
- `Doing` - Date (when actively being worked on)
- `Done` - Date (completion timestamp)

**ESTIMATION & TRACKING**
- `Planned Hrs.` - Number (manual estimate OR auto-calculated from Time Blocks)
- `Logged Time` - Rollup from Time Entries (actual time spent)

**RELATIONS**
- `Time Entries` - Relation to Time Entries database
- `Time Blocks` - Relation to Time Blocks database

---

### Performance Metrics (Keep - Just Added)

- `Schedule Variance (hrs)` - Number (TOAD calculated)
- `Schedule Adherence Status` - Select (TOAD calculated)
- `Estimation Variance (hrs)` - Number (TOAD calculated)
- `Estimation Accuracy %` - Number (TOAD calculated)
- `Estimation Status` - Select (TOAD calculated)
- `Context Switches` - Formula: `Time Entries.length()`
- `Focus Score` - Select (TOAD calculated)

---

### Time Block System (Needs Implementation)

**New Formula Properties to Add:**
1. `Has Time Blocks` - Formula: `Time Blocks.length() > 0`
2. `Time Block Count` - Formula: `Time Blocks.length()`
3. `Effective Planned Hours` - Formula:
   ```
   if(prop("Has Time Blocks"), 
     prop("Total Block Duration (hrs)"), 
     prop("Planned Hrs.")
   )
   ```

**New Rollup Properties:**
4. `Total Block Duration (mins)` - Rollup from Time Blocks → Duration (mins) → Sum
5. `Total Block Duration (hrs)` - Rollup from Time Blocks → Duration (mins) → Sum, then divide by 60 in formula

## Time Blocks Database Structure

### Required Properties

**CORE**
- `Name` - Title (auto-generated by TOAD)
- `Task` - Relation to Tasks (parent task)
- `Start Time` - Date
- `End Time` - Date
- `Duration (mins)` - Formula: `dateBetween(prop("End Time"), prop("Start Time"), "minutes")`
- `Duration (hrs)` - Formula: `prop("Duration (mins)") / 60`

**METADATA**
- `Block Number` - Number (auto-set by TOAD based on chronological order)

### Phase 3: Create TOAD Time Block Manager

**New Python Module:** `toad/productivity/time_block_manager.py`

Features:

5. CLI command: `toad time-blocks update`

## Benefits of This Structure

1. **Cleaner**: Removes 9+ unused/deprecated properties
2. **Clearer**: Each property has a single, well-defined purpose
3. **Flexible**: Time Blocks allow breaking up long tasks without creating duplicate tasks
4. **Accurate**: Metrics use actual block durations instead of rough estimates
5. **Maintainable**: TOAD handles complex calculations, Notion stores clean data
