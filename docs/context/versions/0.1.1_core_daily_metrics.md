# 0.1.1 Core Daily Metrics

## Objective
Aggregate individual task metrics into a daily summary to track productivity trends. This will be triggered by a `toad sync` command.

## Key Metrics

### Core Aggregations
- **Daily Performance Score**: An aggregated score based on the formula from `0.1.0_core_task_metrics.md`.
- **Efficiency**: An aggregated efficiency score based on the formula from `0.1.0_core_task_metrics.md`.

### Task Relations
The `Daily Productivity Metrics` table needs to have relations to the `Tasks` table to show the state of tasks at the end of the day. The key relations are:
- **Active**: Tasks that were started but not completed.
- **Worked**: All tasks that had time logged against them.
- **Done (or completed)**: Tasks that were marked as complete.

### Additional Daily Metrics
- **Adherence**: How well the actual work followed the planned schedule.
- **Focus**: A measure of how much time was spent in focused work sessions versus breaks.
- **Completion Rate**: The percentage of planned tasks that were completed.
- **Planning Accuracy**:
    - Total hours planned vs. total hours worked.
    - Hours worked broken down by task.
- **Work Patterns**:
    - Number of breaks taken.
    - Longest working session.
    - Longest break.
