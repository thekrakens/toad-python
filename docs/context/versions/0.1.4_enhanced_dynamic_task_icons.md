# 0.1.4 Enhanced Dynamic Task Icons

## Objective
Create a process to dynamically update task icons in Notion based on their status. This will be handled by a `toad sync` command.

## Icon Logic
- **Planned**: Open circle for tasks with no time logged.
- **In Progress**:
    - A circle that fills up in 8 increments based on the ratio of worked time to planned time.
    - The circle is green if the task is within its planned timeframe.
    - The circle turns yellow if the worked time exceeds the planned time by 2 hours.
    - The circle turns red if the worked time exceeds the planned time by 4 hours.
- **Categorization**:
    - Different icons for work vs. personal tasks.
    - A special icon for unplanned tasks.
    - A red bug icon for unplanned tasks with "bug" or "fix" in their tags.

## Feedback
This is a great feature for at-a-glance status updates. The logic is well-defined. The implementation will require a mapping of states to icon URLs, which can be stored in the TOAD configuration. We will need to source or create the icons for each state.
