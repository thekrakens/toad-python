# 0.1.2 Core Productivity ETL

## Objective
Ensure the TOAD ETL process is robust and reliable. This involves extracting data from Notion, transforming it, and loading it into the local SQLite database and back into Notion where necessary.

## Key Processes
- **Data Extraction**:
    - Fetch all relevant data from Notion databases (Tasks, Time Entries, etc.).
    - Handle API errors and rate limiting gracefully.
- **Data Transformation**:
    - Clean and preprocess the raw data.
    - Calculate the metrics defined in `0.1.0` and `0.1.1`.
    - Structure the data for loading into SQLite.
- **Data Loading**:
    - Load the transformed data into the local SQLite database.
    - Update Notion databases with aggregated metrics.
    - Implement smart data invalidation to avoid reprocessing unchanged data.
