# 0.1.5 Custom Generated Graphics

## Objective
Create a process for generating custom, TOAD-themed icons for projects using an LLM API.

## Workflow
1. **Trigger**: A CLI command will initiate the process.
2. **Prompt Generation**: The command will generate a detailed prompt for the LLM, including instructions on the TOAD theme, the project context, and desired aesthetic (simple, clean, colorful).
3. **Image Generation**: The prompt will be sent to an LLM image generation API.
4. **Candidate Review**: The API will return a few candidate icons.
5. **Manual Selection**: The user will manually review the candidates and select the best one.
6. **Import**: The selected icon will be moved to a designated directory in the TOAD project, making it available for use in Notion.

## Feedback
This is an innovative feature that could add a lot of personality to the Notion workspace. The workflow is well-thought-out, separating the automated generation from the manual selection. The key will be to craft effective prompts for the LLM to get the desired results. It would be beneficial to experiment with different LLM providers to see which one produces the best results for this use case.
